# Plaquiz AI - Quantitative Aptitude Solver 🧠

Plaquiz AI is a sleek, AI-powered full-stack application designed to help students and job seekers master quantitative aptitude. It provides an interactive MCQ interface with instant step-by-step solutions generated by AI.

## ✨ Features

- **Interactive MCQ Interface**: Modern card-based UI with feedback on every answer.
- **AI-Powered Solutions**: Get detailed explanations and core concepts for any question.
- **Batch Processing**: Solve all answered questions in one click, processed in efficient batches of 5.
- **Responsive Design**: Built with React and TailwindCSS (v4) for a premium experience on all devices.
- **Micro-Animations**: Uses Lucide icons and CSS transitions for a fluid feel.

## 🛠 Tech Stack

- **Frontend**: React (Vite), TailwindCSS v4, Lucide-Icons, Axios.
- **Backend**: Node.js, Express, OpenRouter API (OpenAI-compatible).
- **Data**: 120+ pre-parsed MCQ questions.

## 🚀 Getting Started

### Prerequisites

- Node.js installed on your machine.
- An OpenRouter API Key ([Get one here](https://openrouter.ai/)).

### Installation

1. **Clone/Navigate to the project**:
   ```bash
   cd plaquiz
   ```

2. **Backend Configuration**:
   ```bash
   cd backend
   npm install
   cp .env.example .env
   ```
   *Edit `.env` and add your `OPENROUTER_API_KEY` and preferred `OPENROUTER_MODEL`.*

3. **Start the Backend**:
   ```bash
   node server.js
   ```

4. **Frontend Configuration**:
   ```bash
   cd ../frontend
   npm install
   ```

5. **Start the Frontend**:
   ```bash
   npm run dev
   ```

## 📂 Folder Structure

- `/frontend`: React application source code.
- `/backend`: Express server and AI logic.
- `/backend/data`: Contains the question bank in JSON format.
- `/backend/parse.js`: Utility script used to parse the raw question text.

## 🤖 AI Customization

You can change the AI model used for solving by updating the `OPENROUTER_MODEL` variable in the backend `.env` file. Recommended models:
- `openai/gpt-3.5-turbo` (Fast & Reliable)
- `google/gemini-2.5-flash` (Efficient)
- `meta-llama/llama-3-8b-instruct` (Open Source)
